# Security Policy

Editable Motion Paths is a local Blender add-on and currently does not require network access.

## Reporting a security issue

Please do **not** open a public issue for a vulnerability that could expose user data, execute unintended code, or affect the operating system.

Use GitHub's private vulnerability reporting feature if enabled, or contact the maintainer privately through the repository profile.

Include:

- affected version;
- Blender version and OS;
- reproduction steps;
- impact;
- minimal proof of concept if appropriate.

## Supported versions

During the prototype phase, only the latest published version receives fixes.
