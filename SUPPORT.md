# Support

Editable Motion Paths is currently a community prototype, not a commercial support product.

## Bugs

Use the GitHub **Bug report** issue form.

## Feature requests

Use the GitHub **Feature request** form when you can describe a concrete workflow problem and proposed interaction.

## Open-ended feedback

Use GitHub **Discussions** for broader animation-workflow feedback, UX debate and ideas that still need exploration.

## Crashes

For a Blender crash, include the crash log and exact reproduction steps. A minimal `.blend` file is strongly preferred.

## Private/security reports

See [SECURITY.md](SECURITY.md).
