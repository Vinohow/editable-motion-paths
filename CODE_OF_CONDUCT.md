# Code of Conduct

This project aims to maintain a professional, constructive and welcoming space for Blender users and contributors.

## Expected behavior

- Be respectful and specific.
- Critique behavior, code and UX - not people.
- Assume good faith while asking for reproducible evidence.
- Keep issue threads focused on the reported problem.
- Welcome users with different levels of animation and Python experience.

## Unacceptable behavior

- Harassment, threats or personal attacks.
- Discriminatory or demeaning language.
- Deliberate disruption or spam.
- Publishing another person's private information.

## Moderation

Maintainers may edit, hide or remove content that makes collaboration unsafe or unproductive, and may restrict participation for repeated abuse.

For sensitive reports, contact the maintainer privately using the contact method listed on the repository profile rather than opening a public issue.
