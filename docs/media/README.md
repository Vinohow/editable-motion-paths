## Main demo storyboard

Keep the main loop short and understandable without audio:

1. 0-2 s - show an object and its motion path.
2. 2-5 s - drag the middle path key; path updates.
3. 5-8 s - Alt-click the key to make a corner.
4. 8-12 s - Alt-drag to draw a smooth tangent.
5. 12-15 s - drag a handle and press X/Y/Z for a constraint.
6. 15-18 s - final motion/path result.

Avoid showing debug panels, crashes, test scenes with clutter or old UI.

## GIF recommendations

- Crop tightly around the Blender viewport and relevant panel.
- 1280 px wide or less is usually enough for README viewing.
- 15-24 fps is sufficient for UI demonstration.
- Keep the file reasonably small; use MP4 on release/forum posts if GIF becomes too heavy.
- Add short on-screen labels only when the gesture would otherwise be ambiguous.
